## Image kernel

`patches/linux/` is what `scripts/build-kernel.sh` applies on v7.3 for the image kernel (current release 7.3.0+opi5.15; versions are `<mainline>+opi5.<rev>`). It is recreated as fork branch `opi5/image`. It holds the topics above that are marked as in the image, plus carried fixes; the topic directories are the reference for upstreaming. The feature branches based on `image` are not in it yet; most of them are in the 7.3.0+opi5.16 release candidate, which is under test. Which patch range comes from where, and how it was tested: [docs/image-kernel/MANIFEST.md](docs/image-kernel/MANIFEST.md).

Patches in patches/linux: 479; other patch directories: alsa-ucm-conf, chromium, ffmpeg, firefox, gst-plugins-good, gstreamer, jellyfin-desktop, linux-extra, linux-hold, mpv, tf-a, u-boot, upstream, weston.
